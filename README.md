# 📝 Employee Management System (Angular + JSON Server)

Welcome to my first Angular project — an **Employee Management System** built to understand Angular fundamentals like components, services, routing, HTTP requests, and two-way data binding. For the backend, I’ve used **JSON Server** as a mock database.

---

## 📌 Project Features

- 📋 List all employees
- ➕ Add new employee
- ✏️ Edit existing employee details
- ❌ Delete an employee
- 📦 Mock backend using JSON Server

---

## 🚀 Technologies Used

- **Angular** 
- **Angular CLI**
- **JSON Server**

---

## 🛠️ How to Run the Project

### 1️ Install Dependencies
npm install

### 2  Start JSON Server
 json-server --watch db.json

### 3  Run Angular Application
ng serve
